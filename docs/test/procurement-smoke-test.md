# 采购与资产管理系统 · 冒烟测试用例

> 阶段四·冒烟用例产物 · 创建日期：2026-06-11 · 状态：草稿
> 用途：每次提测/部署后的**准入检查**——关键路径最小集合，验证基本可用性；任一不通过直接打回，不进入全量功能测试。
> 来源：详设关键路径 `U0→U1→U2→U5→U6→U7→U8→U9→U11`（+ U12/U13/U14）+ `procurement-test-case.md` 中的 P0 用例串联。

---

## 冒烟原则

- **只覆盖关键主线**：核心业务闭环 + 必经路径（P0 为主），单条失败即阻断。
- **快**：整套应能在 ≤30 分钟跑完，步骤精简。
- **可重复**：用例独立、数据可重置（按前缀造数、可清理），每个版本都能重跑。
- **顺序串联**：本冒烟为一条端到端主线，数据从上一步流向下一步（组织→预算→审批→采购→入库→库存→领用→出库→盘点→对比→工作台）；建议按编号顺序执行。
- **角色切换**：主线跨 admin/editor/purchase_mgr/dept_mgr/warehouse/requester，按步骤切换登录账号。
