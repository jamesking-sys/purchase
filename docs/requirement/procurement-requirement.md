> 阶段一·需求确认产物 · 创建日期：2026-06-04（2026-06-05 按新模板重构） · 状态：已确认
> 下游：阶段二 `tkxm-prd`（产品文档）→ `tkxm-prototype`（原型图）
> 来源：`docs/requirement/采购项目.txt`

## 1. 背景与问题

- **当前痛点 / 用户问题**：项目采购从「立项预算」到「资产入库、领用、盘点」全过程缺少统一系统支撑——预算与科目割裂、审批靠线下、采购与库存数据不连续，事后难以追溯一笔采购的来龙去脉。
- **为什么现在做**：需要把「预算 → 科目 → 两级审批 → 采购执行 → 验收入库 → 领用/出库 → 盘点」做成一条**可追溯的闭环**，支撑多项目并行管理，并为后续资产折旧、预算变更台账等能力预留扩展位。

## 2. 核心功能点

> 角色（轻量 RBAC）：编制人（项目组/采购员）、采购主管、部门主管、仓管员、领用人；部门与项目组作为数据归属维度，不做复杂组织树与字段级授权。

1. **预算导入** — 结构化模板（Excel/CSV）导入预算明细行；立项/预算文档作附件上传留档（不做文档自动解析抽取）。
2. **预算科目划分与管理** — 按预算逐级划分科目；科目为**多级树形结构，默认 5 级、可在末级向下扩展**，金额仅挂叶子级；支持查询与**模糊搜索**。
3. **科目比对与新增** — 划分出的科目与库中现有科目对照；对缺失科目提供「新增科目」，人工确认后入库。
4. **两级审批** — 预算/科目确认后串行审批：采购主管 → 部门主管；任一节点**驳回则退回编制态**，编制人改后重新提交、重走审批；记录驳回意见与状态流转。
5. **采购执行 + 验收入库** — 审批通过进入执行；记录采购结果，**供应商名称/合同号为可选轻量字段**（不建独立供应商/合同模块）；支持上传到货单；支持**多次到货分批验收入库**，入库生成/累加库存记录。
6. **领用 / 出库** — 项目组成员发起领用申请 → **仓管员核库存并审批出库** → 出库扣减库存（库存不足不可超发）。
7. **盘点** — 按部门/项目组列出资产物料定期盘点；生成盘盈/盘亏差异明细，确认后据实调整库存并留盘点记录。
8. **预算 vs 实际（只读）** — 采购实际支出与预算对比**仅展示**，不做预算余额核减/超预算拦截。

## 3. 范围三分类

- **本期做**：第 2 节全部功能点 + 多项目轻量 RBAC + 结构化模板导入；预算与实际**仅展示对比**。
- **暂不做但预留**：
  - **物料消耗与资产折旧**：库存/资产记录预留生命周期状态与价值字段位，便于后续接入领用消耗、折旧计提。
  - **预算变更与台账输出**：预算/科目模型预留版本/变更记录维度；预算余额核减逻辑预留接入点（本期仅展示）。
- **明确不做（Non-goals）**：
  - 立项文档自动解析抽取预算。
  - 完整供应商主数据 / 合同管理模块。
  - 细粒度组织树与字段级授权。
  - 预算占用/可用余额实时核减与超预算拦截。

## 4. 关键流程（主线）

```
导入预算（模板）/ 上传立项文档留档
   → 逐级划分预算科目（多级树，默认 5 级，金额挂叶子级）
   → 与库中科目比对 → 缺失科目人工新增确认
   → 提交审批：采购主管 → 部门主管（驳回则退回修改重提）
   → 审批通过，进入执行
   → 采购执行（可填供应商/合同）→ 上传到货单
   → 多次到货验收入库 → 生成/累加库存
   → 项目组发起领用 → 仓管员核库存并审批出库 → 扣减库存
   → 定期盘点 → 记录盘盈/盘亏差异 → 确认后调整库存
```

## 5. 验收标准 / 交付要求

| 编号 | 对应功能点 | 验收标准（可判定） | 优先级 |
|---|---|---|---|
| AC-1 | 预算导入 | 能从结构化模板（Excel/CSV）导入预算明细成功落库；格式/数据错误行可定位提示；立项文档可作附件上传留档 | 高 |
| AC-2 | 科目划分与管理 | 科目以多级树（默认 5 级、可向下扩展）展示，金额只能挂叶子级；科目模糊搜索可按名称/编码命中 | 高 |
| AC-3 | 科目比对与新增 | 比对能识别库中缺失科目，人工确认后新增入库，后续可复用 | 中 |
| AC-4 | 两级审批 | 一笔预算可走完 采购主管 → 部门主管 两级通过；任一节点驳回退回编制态，可修改后重新提交重走审批；驳回意见与流转历史可查 | 高 |
| AC-5 | 采购执行 + 验收入库 | 审批通过后可创建采购执行（供应商/合同可选）；可上传到货单；支持多次到货分批入库，累计入库不超过采购数量，入库后库存正确生成/累加 | 高 |
| AC-6 | 领用 / 出库 | 项目组成员可发起领用；仓管员核库存后审批出库并扣减库存；库存不足时拒绝出库（零超发） | 高 |
| AC-7 | 盘点 | 可按部门/项目组列出资产物料发起盘点，记录盘盈/盘亏差异，确认后据实调整库存并留盘点记录 | 中 |
| AC-8 | 预算 vs 实际 | 可查看某预算的实际采购支出与预算对比（只读展示），不发生余额核减 | 中 |
| AC-9 | 多项目轻量 RBAC | 各角色仅能执行其职责对应操作；核心业务对象（预算/科目/采购/库存/领用/盘点）均带项目组维度，数据按归属隔离统计 | 中 |

- **交付物**：一套覆盖「立项预算 → 预算科目 → 两级审批 → 采购执行 → 验收入库 → 领用/出库 → 盘点」的多项目采购管理系统，全流程状态可追溯。
- **非功能要求**：
  - **设计风格 Semi Design**（与前端脚手架 Semi UI 一致，传递给阶段二原型）。
  - 资产/物料按「项目组 → 所属部门」归属，作为数据隔离与统计维度。
  - 多项目并行；用户规模与并发为常规企业内部系统量级，无特殊高并发/多租户要求。
  - 库存扣减零超发、入库不超收；审批与库存全程可审计追溯。
